Inorganic Nomenclature

Chemical names are a code: they tell you exactly what is in a compound and in what ratio. Learn the patterns once and you can name — or write the formula for — almost any inorganic compound.

Ionic Compounds

Name the cation first, then the anion. A monatomic cation keeps the element name (sodium, calcium); a monatomic anion takes the -ide ending (chloride, oxide, sulfide). NaCl is sodium chloride; MgO is magnesium oxide.

Metals that form more than one charge — most transition metals — need a Roman numeral for the charge: Fe2+ is iron(II), Fe3+ is iron(III). Find the charge from the anion: in FeCl3, three Cl− give −3, so iron is +3: iron(III) chloride. (The older -ous/-ic names, like ferrous and ferric, are no longer used.)

Polyatomic Ions

Memorize these — they appear everywhere:

  • NH4+ ammonium, OH− hydroxide, CN− cyanide
  • NO3− nitrate, NO2− nitrite, CO32− carbonate, HCO3− hydrogen carbonate (bicarbonate)
  • SO42− sulfate, SO32− sulfite, PO43− phosphate, ClO3− chlorate, ClO4− perchlorate, ClO− hypochlorite
  • CrO42− chromate, Cr2O72− dichromate, MnO4− permanganate, C2H3O2− acetate

The -ate / -ite pattern: -ate is the more common, more oxygenated ion; -ite has one fewer oxygen. Per- -ate adds one more oxygen; hypo- -ite removes one. When a polyatomic ion needs a subscript, put it in parentheses: Ca(OH)2, Al2(SO4)3.

Example: Name Fe2O3. Three O2− give −6, so the two irons must total +6: each iron is +3. The name is iron(III) oxide.
Example: Write the formula for calcium phosphate. Ca2+ and PO43− must balance to zero: the lowest common multiple of 2 and 3 is 6, so three Ca2+ (+6) and two PO43− (−6): $$\text{Ca}_3(\text{PO}_4)_2$$

Molecular (Covalent) Compounds

Two nonmetals share electrons, and the name uses Greek prefixes to give the numbers: mono- (1), di- (2), tri- (3), tetra- (4), penta- (5), hexa- (6), hepta- (7), octa- (8), nona- (9), deca- (10). The first element usually drops mono-; the second element always takes -ide. CO is carbon monoxide, CO2 is carbon dioxide, PCl5 is phosphorus pentachloride.

Example: N2O5 — two nitrogens, five oxygens: dinitrogen pentoxide.

Acids

Binary acids (hydrogen + one other element) take hydro- -ic acid: HCl is hydrochloric acid, HBr is hydrobromic acid, H2S is hydrosulfuric acid.

Oxoacids (hydrogen + a polyatomic ion with oxygen) follow the ion: an -ate ion gives an -ic acid, an -ite ion gives an -ous acid. H2SO4 (sulfate) is sulfuric acid, H2SO3 (sulfite) is sulfurous acid, HNO3 (nitrate) is nitric acid, HNO2 (nitrite) is nitrous acid, HClO4 (perchlorate) is perchloric acid.

Example: H3PO4 contains the phosphate ion, PO43− — an -ate ion, so the acid is phosphoric acid.

Hydrates

A hydrate is an ionic compound with water molecules locked into its crystal. Name the compound, then add a prefix + "hydrate" for the waters, joined with a dot in the formula: CuSO4·5H2O is copper(II) sulfate pentahydrate. Others: Na2CO3·10H2O is sodium carbonate decahydrate (washing soda); MgSO4·7H2O is magnesium sulfate heptahydrate (Epsom salts).

Practice Problems

  1. Name CuCl2.
  2. Name SO3.
  3. Write the formula for aluminum sulfate.
  4. Name HClO4.

Answers: 1. Copper(II) chloride   2. Sulfur trioxide   3. Al2(SO4)3   4. Perchloric acid
